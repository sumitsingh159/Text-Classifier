# Linguistic Intelligence Engine

This project leverages a fine-tuned BERT model to perform high-accuracy text classification across various categories. It analyzes semantic patterns and linguistic nuances to provide real-time insights into the nature of the input text. Built for scalability and precision, it serves as a robust tool for automated content analysis and intelligent data categorization.

## Features
- **Model:** Fine-tuned `bert-base-uncased`
- **Categories:** Technology, Sports, Politics, Entertainment
- **Interface:** Modern, responsive Gradio UI with custom CSS (by sumitsingh159)
- **Performance:** Optimized for CPU/GPU inference with LRU caching
